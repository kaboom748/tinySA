Niveau RF

Le cœur TinySA4 de ce commit borne M_GENLOW à environ −115…−18.5 dBm, plus l'offset de calibration de sortie éventuel. Le texte d'aide level -76..-6 dans le shell est ancien et ne correspond pas aux constantes TinySA4 de ce build.

External gain

Commande exacte : ext_gain -100.0..+100.0. C'est une correction d'affichage/référence ; ce n'est pas un atténuateur RF supplémentaire.

Type

L'UI officielle force SPAN=0 et LEVEL CHANGE=0 lorsqu'on active une modulation. Cette application reproduit ce comportement avant AM/FM.

Fréquence de modulation

Le setter interne accepte jusqu'à 10 kHz en général, mais limite FM à 3.5 kHz. L'écran du build indique 1 Hz…3.5 kHz.

AM depth

Commande : modulation depth <0..100>.

FM deviation

Le shell attend des Hz : 50 kHz devient modulation deviation 50000. Le firmware stocke la valeur avec une granularité de 100 Hz.

Profils complets

Sweep natif — fréquence

Envoie sweep START_HZ STOP_HZ POINTS. L'Ultra propose jusqu'à 450 points dans l'UI.

Sweep — centre / span

Configurer un span non nul coupe d'abord la modulation dans cette application, comme le fait l'UI officielle.

Temps / niveau / précision

Le shell de ce commit annonce sweeptime 0.003..60, même si le texte de l'UI mentionne jusqu'à 600 s.

Exécution

Commandes natives : sweep normal|precise|fast|noise|go|abort.

Deux tons manuels

Utilise sweep cw, donc la configuration du générateur reste cohérente avec l'UI.

Motif lent via USB

Ce mode sert au test CFO lent. WebSerial n'est pas un générateur FSK à timing précis.

La sonde demande uniquement des usages/états ; elle n'utilise pas levelchange ? car ce firmware l'interpréterait comme une valeur 0.

Commande freq directe

Cette commande appelle pause_sweep(). Utilise plutôt CW dans l'onglet Générateur pour le fonctionnement normal.

Référence CAL

Connecteur CAL uniquement.

Calibration fréquence — lecture seulement

actual_freq représente la référence 30 MHz mise à l'échelle dans le firmware ; ce n'est pas un fréquencemètre RF. Les écritures de calibration sont volontairement absentes de cette interface.

Presets appareil

Écrit/lit les zones de preset du tinySA.
Pourquoi je n'expose plus « ultra auto/on/off » comme option du générateur

La commande ultra off|on|auto|start|harm agit sur la configuration Ultra globale (config.ultra, seuils et harmoniques). Ce n'est pas le sélecteur Cleanest/Highest Accuracy de la sortie générateur. Le vrai sélecteur de sortie est output normal|mixer.

Console brute

Chaque commande est terminée par CR (\r).
